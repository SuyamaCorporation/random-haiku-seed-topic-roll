# 俳句お題ランダムロール

サイコロを振るように季語・情景・感情の3要素をランダムに組み合わせて俳句のお題を生成するアプリ。お気に入りの組み合わせを保存して下書きを書き留められる。

## 機能
- 季語30種・情景30種・感情20種の3カテゴリホイール
- スロットマシン風の数字サイクルアニメーションから結果へのロールエフェクト
- 「お題を振る！」大ボタンで新しい組み合わせを即生成
- 結果表示後にそのまま俳句の下書きを書けるテキストエリア
- ハートボタンでお気に入りに保存（最大20件）
- お気に入り一覧から過去の組み合わせと下書きを再読み込み可能
- localStorageにお気に入りと下書きを保存
